    Install on Fedora

    1. Download the installer, its signature and publisher public certificate using the links above. Save them together in Downloads. You do not need Node.js or this project's source ZIP.
    2. Compare the public fingerprint shown below with the publisher's fingerprint obtained through a separately trusted channel. A certificate downloaded beside an installer is not independent proof of identity.
    3. Open a terminal in Downloads. Check the certificate and signature using the commands below. Continue only if GPG succeeds and the fingerprint matches. Never run a download with a missing, invalid or unexpected signature. 
    
      
    
      
    After successful verification, install as your normal user, not with sudo:
    
      
    
      
    
        The installer includes its runtime and database components. Installation does not download
        dependencies. Return to this site on the same computer after installation. Open
        Administrator setup and follow its pairing/setup-code
        instructions. Keep codes and account passwords private. Do not expose the local helper to
        the internet.
      
    
      
    Android: browse without an account or database
    
      
    
        Enter HERO browsing mode. Android visitors without a session can
        open every HERO page destination without logging in. Private records and all database-backed
        actions remain unavailable. Page destinations are browsing shells, not copies of private
        desktop data. No Fedora installer, phone-to-laptop database connection or simulated login is
        used.
