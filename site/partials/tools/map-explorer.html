World Map Baseline

Capture all five map layers for the entire world or a region of your chosen size centered on a character. Baselines are stored in this site's own SQLite file on this device (about 20 bytes per tile); Wurm server files are read-only. Baselines can be exported to a JSON file, imported again, or deleted without affecting the game.
