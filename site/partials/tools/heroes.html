Connect local database

This page stores worlds in the project's local database helper; the pairing code comes from Wurm Tools, not from SQLite. SQLite is included as a project dependency, so you do not need to install or run a separate SQLite server.

  1. Open a terminal in your Wurm Tools project folder.
  2. If dependencies are not installed yet, run npm install.
  3. Start the local helper and development site with npm run dev.
  4. In another terminal in the project folder, run npm run helper:pair-code. The code expires after 10 minutes.
  5. Enter that code below to connect this browser to the local database.
