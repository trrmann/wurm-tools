Works after the one-time setup below registers the wurm-helper:// launcher (Windows and Fedora).

One-time setup, both Windows and Fedora: npm run helper:protocol:install

The browser cannot start programs itself, so the helper must run on your computer. Run these in a terminal inside the wurm-tools folder, then this page will connect automatically.

Fedora / Linux (start now and at every login): npm run helper:startup:install — or once only: npm run helper

Windows (PowerShell; start now and at every logon): npm run helper:startup:install — or once only: npm run helper

This site must be one of the helper's allowed origins. For other addresses set WURM_ALLOWED_ORIGINS.

Pair this browser with the local helper. Generate a one-time code in a terminal with npm run helper:pair-code. It expires after 10 minutes. Allow local network access if your browser asks.
